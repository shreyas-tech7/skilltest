# Decisions

One line per choice: the options and the reason.

- 2026-11-20 Name: picked `skilltrial` for the package and the command. `skilltest` is free on PyPI but taken on npm by a package that calls itself "The testing framework for Agent Skills" (version 0.10.0), so it fails the section 4 rule. `skilltrial` answered 404 on PyPI and npm, and a web search found no known GitHub project with that name. The repo keeps the name `skilltest` until Shreyas renames it (docs/HUMAN_STEPS.md).
- 2026-11-20 Spec source: agentskills.io answered 403 through the proxy, so the spec came from raw.githubusercontent.com (agentskills/agentskills main, docs/specification.mdx, fetched 2026-11-20, sha256 in docs/SPEC.md).
- 2026-11-20 Base branch: origin on GitHub was empty, so `claude/build-skilltest` starts from `main` in the build session's local copy (commit 1e74ec4, the README commit). The coordinator merges through a PR.
- 2026-11-20 Severity: "must" rules from the spec are errors. "Should" and "recommended" lines from the spec are warnings labeled spec guidance. Anything the spec does not say is a warning labeled style advice, as the brief asks.
- 2026-11-20 Unknown frontmatter fields: the spec lists six fields but does not forbid others, so an unknown field is style advice (SKL201), not an error.
- 2026-11-20 A missing referenced file is style advice (SKL203). The spec does not say it, even though it is a real defect.
- 2026-11-20 Token estimate: ceil(characters / 4), with characters as Python string length. Metadata counts the `name` and `description` values only. Body counts every character after the closing frontmatter line.
- 2026-11-20 Rule commits: the 23 lint rules live in one table. Each rule is its own feature with its own test id, but the rules and their tests went in together in two commits to save session budget.
- 2026-11-20 Flawed variants are generated by `scripts/make_flawed.py` from the clean examples, so each flawed copy differs from its fixed copy by one change.
- 2026-11-20 "Counted by hand" means counted by an independent shell script with `wc -m` (scripts/hand_count.sh), not by the Python code. No human counted them, and the docs say so.
- 2026-11-20 Trigger gold labels: every should-trigger prompt has its own skill as gold. Every should-not prompt has gold "none". Micro precision counts each skill pick, recall counts each prompt whose gold is a skill.
- 2026-11-20 Split: a seeded hash split per skill and per class. Half of each group, rounded up, goes to tuning. Each skill has 10 positives (5 and 5) and 5 negatives (3 tuning, 2 held-out), so the none prompts split 36 and 24. The split was committed before any selector code existed. The whole build ran in one short session, so commit times alone are weak proof of that order.
- 2026-11-20 Bootstrap: 2000 resamples of prompts with replacement, percentile 95% interval, seed 20261120. Standard library random, no numpy.
- 2026-11-20 Third-party skills: `npx skills add` was refused by the permission system. Ponytail, caveman and humanizer rules are applied by hand from the brief.
- 2026-11-20 Baseline selector: BM25 over name and description only, with a "none" threshold. Options were TF-IDF cosine, BM25 and an embedding model. BM25 is standard, offline, needs no download and sees exactly what an agent sees before it loads a skill.
- 2026-11-20 Tuning: grid search over k1, b and the threshold on the tuning set only, best micro F1, ties to the earliest grid point. A second split (seed 20261121) was tuned and scored too, because the held-out score came out above the tuning score and one split could be luck.
- 2026-11-20 Overlap thresholds: cosine 0.20 or more, or 2 or more colliding prompts with the runner up at 0.8 of the leader. Fixed before the first run and not changed after it, so the extra flagged pairs are reported, not tuned away.
- 2026-11-20 Exit codes: 0 clean, 1 findings or a failed check, 2 usage (argparse), 3 no skills or bad input. Options were a single nonzero code or one code per command. Four codes let CI tell "your skill has a problem" from "you called it wrong".
- 2026-11-20 LLM selector view: the prompt shows only names and descriptions, the same view as the baseline, so the two rows compare selectors and not inputs. Record mode refuses any non-https endpoint.
- 2026-11-20 README numbers: every number sits in a generated block filled from `results/`. A test fails on drift and another fails on a digit in prose outside the blocks.
- 2026-11-20 Link checker skips `examples/flawed`, because two of the planted flaws are broken links. CI caught the checker failing on them.
- 2026-11-20 Prompt files: a key other than skill, should_trigger and should_not_trigger is an error. A typo used to drop prompts without a word, which would shrink the eval quietly.
