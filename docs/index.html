skilltrial

skilltrial tests Agent Skills before you ship them. It lints SKILL.md against the spec, estimates the token budget, measures whether the description makes the right skill trigger, and flags skills that compete.

A false trigger is a prompt that should load no skill, where the selector picked one anyway. That skill's body then fills the context window for nothing.
