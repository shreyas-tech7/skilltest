# Commit message

Write one commit message for the staged diff.

## Steps

1. Read the staged diff with `git diff --cached`.
2. Write a subject line in the imperative mood, under 50 characters, with no trailing period.
3. Leave one blank line.
4. Write a body that says why the change was made, wrapped at 72 characters.
5. Add `Fixes #123` when the diff closes an issue the user named.

## Rules

- One logical change per commit. If the diff mixes changes, suggest splitting it.
- Do not describe the code line by line. The diff already shows that.
